# 🐍 Ejercicios y Proyectos en Python

Este repositorio recopila la evolución de mis prácticas en **Python**, abarcando desde fundamentos de lógica y estructuras de control hasta Programación Orientada a Objetos (POO), desarrollo de interfaces gráficas (GUI) con **Tkinter** y conexión a bases de datos con **MySQL**.

---

## 📂 Estructura del Repositorio

Los proyectos están organizados por temática y nivel de progresión:

### 🔹 Fundamentos y Lógica
* **[`Calculadora`](./Calculadora)**: Operaciones aritméticas básicas implementadas en consola.
* **[`Calculadora_funciones`](./Calculadora_funciones)**: Refactorización de la calculadora aplicando modularidad mediante funciones para un código más limpio y reutilizable.
* **[`Cajero_automatico`](./Cajero_automatico)**: Simulación de flujo de transacciones bancarias (consultas, depósitos y retiros) utilizando estructuras condicionales y bucles.

### 🔹 Programación Orientada a Objetos (POO) y Archivos
* **[`Computadoras_POO`](./Computadoras_POO)**: Modelado de clases, herencia, composición y encapsulamiento para gestionar componentes de hardware.
* **[`Maquina_de_Snacks`](./Maquina_de_Snacks)** y **[`Snacks_Poo`](./Snacks_Poo)**: Evolución de un sistema de gestión de inventario y ventas de snacks, pasando de una estructura básica a un diseño orientado a objetos.
* **[`Catalogo_peliculas`](./Catalogo_peliculas)**: Aplicación de gestión de catálogo con persistencia de datos mediante el manejo de archivos.

### 🔹 Interfaces Gráficas (Tkinter) y Bases de Datos (MySQL)
* **[`Login_tk`](./Login_tk)**: Ventana de inicio de sesión con validación de eventos y botones interactivos desarrollada con Tkinter.
* **[`Fit_Tkinter`](./Fit_Tkinter)**: Interfaz gráfica de usuario para gestión de gimnasios/rutinas, integrando componentes visuales avanzados en Tkinter.
* **[`ZonaFit_Mysql`](./ZonaFit_Mysql)**: Sistema de gestión con conexión a base de datos relacional **MySQL** para operaciones CRUD (Crear, Leer, Actualizar, Eliminar).

---

## 🛠️ Tecnologías y Conceptos Aplicados

* **Lenguaje:** Python 3
* **Paradigmas:** Programación Estructurada y Programación Orientada a Objetos (POO)
* **Interfaces Gráficas:** Tkinter
* **Bases de Datos:** MySQL (Integración Python - MySQL)
* **Otros:** Manejo de archivos, control de excepciones y modularización.

## 🚀 Cómo ejecutar los proyectos

1. **Clona este repositorio** en tu máquina local:
   ```bash
   git clone https://github.com/SaintXini/Ejercicios_Python.git
   ```

2. **Entra a la carpeta** del proyecto que desees probar:
   ```bash
   cd Ejercicios_Python/Nombre_De_La_Carpeta
   ```

3. **Ejecuta el archivo principal** de Python (por ejemplo, `main.py` o `app.py`):
   ```bash
   python nombre_del_archivo.py
   ```

> **Nota:** Para proyectos con MySQL como `ZonaFit_Mysql`, asegúrate de tener el servidor activo y configuradas tus credenciales de conexión.
